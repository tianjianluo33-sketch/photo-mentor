# 网站雏形实施状态

本文件记录静态网站版本的范围。前期对话内 HTML 原型的检查结果保留在 [原型说明](../原型说明.md)，不作为本版本已经通过检查的证据。

## 交付范围

| 能力 | 本版本范围 | 未接入或不作出的承诺 |
| --- | --- | --- |
| 两个独立入口 | 互动学习与现场指导为同级入口，可分别直接进入 | 使用现场指导不要求先完成课程 |
| 三节互动课程 | 曝光与运动、景深、构图；本机规则计算与示意反馈 | 不代表真实相机或完整光学仿真 |
| 现场指导 | 目标、设备、反馈深度和现场条件参与示例方案选择 | 无真实图像理解、实时视频分析或模型调用 |
| 风格参考 | 教学方法卡和原创示意，可将意图带入相关流程 | 不代表拥有名师作品库或已授权的大师人格模型 |
| 图片与对比 | 个人图片只在浏览器预览和对比，用户选择偏好 | 不自动分析个人图片，不自动判定重拍更好 |
| 学习记录 | 在当前浏览器保存实际提交与提示使用信息 | 无账号、云同步或掌握程度认证 |
| URL 与构建 | hash 导航、相对静态资源路径，支持仓库子路径 | 无需后端路由，但仍需单独发布静态产物 |
| CI 与部署 | CI 检查所有推送及 PR；独立 Pages 工作流在发布分支代码变动后测试、构建并部署 | 无真实 AI 服务或模型密钥 |

## 发布说明

用户于本次任务授权线上部署或公开代码库。私有仓库启用 Pages 时，GitHub 返回当前账号方案不支持；随后按授权将此仓库设为公开并发布。

`pages.yml` 只发布 `dist/` 静态产物。向 `codex/website-scaffold` 推送代码会在测试和构建成功后自动更新网站；文档变更不触发部署。首次发布版本为 `45a0a1b`。
